# Política de seguridad

Este es un prototipo académico. Si encuentras una vulnerabilidad, repórtala de forma privada con
**GitHub Private Vulnerability Reporting** (pestaña *Security* → *Report a vulnerability*) en lugar de
abrir un issue público.

Incluye: descripción, pasos para reproducir, impacto estimado y, si es posible, una propuesta de
corrección. Responderemos en cuanto sea posible durante el periodo académico.

El modelo de amenazas y los controles están documentados en `docs/seguridad/`.
